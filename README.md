# <img src="frontend/public/assets/polka-mark.svg" width="40" height="40" alt=""> Полка

Самостоятельная электронная библиотека для Windows с Docker Desktop и Linux с Docker Engine. Интерфейс доступен на русском и английском. Документация на русском.

## Первый запуск

Откройте PowerShell или терминал в папке проекта и запустите:

```sh
docker compose up -d --wait
```

Откройте [http://localhost:8080](http://localhost:8080), создайте администратора и добавьте управляемую библиотеку. Через раздел «Библиотеки» загрузите EPUB, PDF или FB2. Для FB2 появится задача конвертации. После её завершения EPUB будет доступен на странице книги.

1. Для папки с существующими книгами настройте `BOOKS_INBOX`, создайте индексируемую библиотеку и запустите предварительный просмотр. Подтвердите план в разделе «Загрузки и импорт».
2. Для внешнего источника добавьте URL в «OPDS-каталоги», откройте каталог и выберите формат книги и библиотеку. Для чтения откройте импортированную книгу из очереди или каталога.
3. Для ридера выпустите персональный токен в настройках. Адреса каталогов заканчиваются на `/opds/v1` и `/opds/v2`.
4. Для продолжения на другом устройстве войдите в тот же аккаунт по доступному этому устройству адресу. Параметры LAN и HTTPS описаны в документации.

Docker сохраняет базу и файлы в томах. Остановка через `docker compose stop` сохраняет данные.

## Документация

### Запуск готового образа из GHCR

Compose использует готовый образ GHCR для Linux x86-64. Ниже приведено значение по умолчанию. Чтобы закрепить другую версию, укажите её тег в `.env`.

```dotenv
POLKA_IMAGE=ghcr.io/benya9669/polka:latest
```

Из папки проекта выполните обе команды. Они подходят и для обновления.

```sh
docker compose pull
docker compose up -d --wait
```

Сервер и обработчик задач используют один образ. При закрытом доступе к пакету сначала выполните `docker login ghcr.io` с именем пользователя GitHub и персональным токеном (classic) с правом `read:packages`.

GitHub Actions собирает приложение и запускает тесты. После успешной проверки в `main` обновляются `edge` и теги `sha-<SHA коммита>` (короткий и полный). Для стабильного выпуска увеличьте номер `X.Y.Z` в файле `VERSION` и отправьте изменение в `main`. Workflow опубликует теги образа `X.Y.Z`, `vX.Y.Z`, `X.Y` и `latest`, затем создаст Git-тег и [GitHub Release](https://github.com/Benya9669/Polka/releases) с описанием изменений.

## Состояние функций

Подтверждения сохранения, импорта и постановки в очередь появляются в углу экрана и видны при переходе между страницами. Ошибки и подробные результаты частичного импорта остаются рядом с формой.

Доступны библиотеки с владельцем и общим доступом, импорт с предпросмотром, точная дедупликация в пределах библиотеки, изменение основных метаданных, конвертация, чтение EPUB и PDF, синхронизация браузеров, OPDS-сервер и импорт из внешних OPDS. В личной библиотеке есть коллекции, избранное, статусы, заметки, выделения EPUB, история сеансов и экспорт в JSON. Администратор может назначать роли, в том числе «Только чтение», и сбрасывать пароли. Для KOReader есть KOSync с привязкой файла, для Sony — скрипт копирования EPUB на съёмный диск. Автоматическое определение совпадений используется для предупреждений в плане. Управляемые оригиналы хранятся по SHA-256.

Каталог поддерживает профили авторов и псевдонимы, подсерии с порядком томов, массовую правку метаданных и объединение карточек с предпросмотром. Управляемые библиотеки поддерживают корзину, отмену импорта и файловую раскладку по шаблону с предпросмотром и возвратом. Сканирование запускается вручную, по расписанию или по событию файловой системы. Расширенные форматы читаются через производные EPUB или PDF. EPUB и PDF можно сохранить для повторного открытия без сети. Для Sony доступны пакет с EPUB 2 и PDF, проверка копий и ручная отметка позиции. Проверки на реальных устройствах ещё предстоят. Подробности приведены в документации.

В настройках можно выбрать язык интерфейса и светлую, тёмную или системную тему. Выбор сохраняется в браузере. Язык также можно изменить на экране входа. В каталоге `Ctrl+K` или `⌘K` переводит фокус в поле поиска.
