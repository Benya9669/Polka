# OPDS

Адреса каталога зависят от `APP_URL`: `/opds/v1` и `/opds/v2`. Выпустите токен в настройках. В OPDS-ридере введите имя пользователя и данный токен как пароль HTTP Basic. API также принимает токен Bearer. Удаление токена сразу отзывает доступ. Доступ ограничен библиотеками пользователя.

OPDS 1.2 показывает все книги, новые поступления, авторов, серии и жанры, поддерживает поиск OpenSearch и пагинацию. OPDS 2.0 отдаёт JSON с навигацией, публикациями, ссылками скачивания и обложками. Клиентская совместимость зависит от приложения и настроек прокси. См. [OPDS 1.2](https://specs.opds.io/opds-1.2) и [OPDS 2.0](https://specs.opds.io/opds-2.0).

В OPDS 1.2 ссылки скачивания содержат размер файла в байтах. При переходе на предыдущую страницу сохраняются раздел каталога и поисковый запрос.

В OPDS 2.0 издание включает доступные метаданные, в том числе описание, язык, издателя, ISBN, жанры и серии. У издания есть собственная запись по ссылке `self`. Сервер проверяет авторизацию клиента и права на библиотеку при запросе публикации, обложки или файла. В многостраничной выдаче ссылка `previous` возвращает к предыдущей странице с тем же запросом. Если публикаций нет, лента предлагает вернуться в начало каталога.

## Внешние источники

Обозреватель показывает фильтры и варианты сортировки, объявленные источником. В OPDS 1.2 это ссылки сортировки и группы фасетов Atom, в OPDS 2.0 — группы `facets`. Для навигации используются ссылки следующей и предыдущей страницы из ответа каталога. [Сортировка OPDS 1.2](https://specs.opds.io/opds-1.2.html#62-sorting-relations) · [Фасеты OPDS 2.0](https://specs.opds.io/opds-2.0.html#24-facets)

Администратор добавляет источники с публичным HTTP(S) URL, Basic по HTTPS или Bearer по HTTPS. В форме источника кнопка «Определить способ входа» запрашивает документ OPDS Authentication и предлагает HTTP Basic, если каталог объявляет этот метод. Для HTTP Basic введите учётные данные каталога, а для Bearer вставьте выданный провайдером токен. Учётные данные отправляются только по HTTPS на сервер, указанный в настройках источника. Пользователи могут просматривать активные источники и импортировать книгу в свою управляемую библиотеку. Внешний поиск соберёт доступные результаты рядом с локальными. Интерактивный OAuth-вход, оплата и DRM пока не поддерживаются.

Раздел «Поиск по источникам» показывает книги из доступных пользователю библиотек, предложения скачать книгу и записи для просмотра или покупки. При совпадении нормализованного названия и имени автора карточка показывает возможные совпадения, в том числе по псевдонимам автора в локальной библиотеке. Выбор карточки для импорта по-прежнему подтверждает пользователь. Внешним источникам отводится до 10 секунд на общий поиск. Опоздавшие и недоступные источники отображаются рядом с успешными результатами.

При импорте издатель и ISBN из внешнего каталога заполняют поля, которых нет в самой книге. Значения, указанные в каталоге, также остаются в истории источника.

Если источник OPDS 2.0 передаёт текст на нескольких языках, «Полка» выбирает русский вариант, затем английский, затем вариант без указанного языка или первую доступную запись. Это правило применяется к названиям, описаниям, именам авторов, издателям и сериям. [Многоязычные метаданные Readium](https://readium.org/webpub-manifest/contexts/default/)

Выберите формат и целевую управляемую библиотеку. Предпросмотр предлагает совместимые карточки по метаданным источника. При выборе карточки сервер сверяет фактические метаданные скачанного файла и добавляет его отдельным изданием. «Импортировать и читать» открывает читалку, когда EPUB или PDF готов к чтению. Для FB2 сначала создаётся EPUB. Серии и номера томов отображаются при наличии в каталоге. [Метаданные серий Readium](https://readium.org/webpub-manifest/contexts/default/#collections-series)

Кнопка «Скачать» рядом с форматом отправляет файл в очередь без добавления в библиотеку. По завершении проверки ссылка «Скачать файл» доступна владельцу задачи 24 часа. Она выдаёт оригинал в исходном формате. Эта операция доступна пользователям с правом загрузки и подходит для учётных записей без управляемой библиотеки.

На странице «Загрузки и импорт» видно, когда файл скачивается, проверяется и конвертируется. Отменить загрузку можно и во время проверки формата, до записи книги в библиотеку. При повторе передача начинается с нуля.

Прямые acquisition-ссылки и open-access добавляются в очередь. Поддерживаются ограничение размера, повтор при временной ошибке, отмена до завершения импорта и загрузка с начала при повторе. Учётные данные источников зашифрованы ключом `source.key` из тома данных. Ссылка скачивания хранится в зашифрованном виде до успешного импорта. В истории остаются источник, безопасный ID записи, время, фактический формат, исходные метаданные и SHA-256. Повторная загрузка создаёт запись в истории и связывается с существующим файлом по SHA-256.

По умолчанию обращения к частным сетям запрещены. Используйте `OPDS_PRIVATE_ALLOW` только для известных локальных источников. Правило требует совпадения имени и IP, в том числе после перенаправления. Учётные данные отправляются только на HTTPS того же origin.
