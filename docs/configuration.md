# Конфигурация

Скопируйте `.env.example` в `.env` для переопределения параметров. По умолчанию HTTP слушает loopback на порту 8080.

| Переменная | Назначение |
|---|---|
| `APP_URL` | Внешний URL, включая нестандартный порт. От него зависят ссылки OPDS, проверка Origin и флаг Secure для cookie |
| `APP_BIND`, `APP_PORT` | Адрес и порт публикации на хосте |
| `FORWARDED_ALLOW_IPS` | IP-адреса или подсети доверенных прокси через запятую. Uvicorn принимает от них `X-Forwarded-Proto` и `X-Forwarded-For`. По умолчанию `127.0.0.1` |
| `BOOKS_INBOX` | Путь к коллекции на хосте Docker. Можно указать абсолютный путь или путь относительно Compose |
| `IMPORT_PATH` | Абсолютный путь к коллекции внутри контейнеров. Compose монтирует `BOOKS_INBOX` сюда в режиме только для чтения. По умолчанию `/inbox` |
| `LIBRARY_PATH` | Папка данных внутри контейнеров. По умолчанию `/data`, корень постоянного тома |
| `ORIGINALS_PATH` | Папка управляемых оригиналов внутри контейнеров. По умолчанию `originals` внутри `LIBRARY_PATH` |
| `EXPORT_PATH` | Папка готовых экспортов внутри контейнеров. По умолчанию `exports` внутри `LIBRARY_PATH` |
| `SETUP_KEY` | Отдельный ключ для создания первого администратора. Задайте его до публикации HTTP |
| `POSTGRES_PASSWORD`, `DATABASE_URL` | Пароль PostgreSQL и строка подключения. При изменении пароля укажите его в обеих настройках, с URL-кодированием в строке подключения |
| `REDIS_URL` | URL Redis для уведомлений фонового обработчика. По умолчанию `redis://redis:6379/0` |
| `TZ` | Часовой пояс процессов. Время API хранится в UTC, браузер отображает локальное время |
| `MAX_BOOK_BYTES` | Лимит файла, по умолчанию 100 МиБ |
| `OPDS_PRIVATE_ALLOW` | Явные пары `имя=IP` через запятую для частных OPDS-серверов |

Изменение `POSTGRES_PASSWORD` после инициализации тома само по себе не меняет пароль существующего пользователя БД. Для нового сетевого развёртывания настройте секреты до первого старта.

Штатный Redis доступен в сети Compose. Для внешнего Redis укажите URL и выделите отдельную базу для экземпляра «Полки». Можно задать `REDIS_URL=` и запустить `docker compose up -d --build --wait app worker`, чтобы обработчик проверял очередь напрямую в PostgreSQL. Такой же режим включается при временной недоступности Redis. [Формат URL Redis](https://redis.io/docs/latest/develop/clients/connection-urls/)

## Пути к книгам и данным

Для хранения в штатном томе укажите, например, `LIBRARY_PATH=/data/library`, `ORIGINALS_PATH=/data/originals` и `EXPORT_PATH=/data/exports`. При выборе пути за пределами `/data` подключите дополнительный постоянный том с таким же путём в `app` и `worker`. Выдайте UID/GID `10001:10001` права записи в предназначенные для этого папки. Папка импорта должна оставаться отдельным монтированием только для чтения.

При изменении путей на работающей установке сделайте резервную копию и остановите `app` и `worker`. Перенесите содержимое каждой перенастроенной папки в её новое расположение, включая существующие оригиналы и экспортные ZIP. Записи хранят относительные пути, поэтому править PostgreSQL при таком переносе не требуется.

## NPMPlus

1. Укажите публичный адрес в `APP_URL`, например `https://books.example.com`. Включите порт, если он отличается от 443.
2. В NPMPlus создайте Proxy Host на тот же домен. Настройте HTTP upstream на адрес и порт «Полки», доступные прокси. В общей сети Docker используйте адрес сервиса и порт 8080. При обращении через порт Docker-хоста укажите `APP_PORT` и привяжите `APP_BIND` к нужному интерфейсу.
3. Задайте `FORWARDED_ALLOW_IPS` с адресом, с которого NPMPlus подключается к Uvicorn. В общей сети удобно закрепить IP прокси. Укажите только адреса управляемых вами прокси, которым доверяете заголовки перенаправления.
4. Выберите TLS-сертификат, включите Force SSL и задайте размер запроса, который пропускает загрузку книги. Например, `client_max_body_size 101m;` для стандартного лимита файла 100 МиБ с полями формы. Опубликуйте для клиентов HTTPS-порт прокси.
5. Если NPMPlus принимает TCP-соединения прямо от клиентов, добавьте `set_real_ip_from unix:;` в Advanced Config этого Proxy Host. Тогда NPMPlus использует адрес TCP-соединения даже при наличии переданного клиентом `X-Forwarded-For`. Если перед NPMPlus есть ещё один доверенный прокси, укажите в этом списке его адрес вместо Unix-сокета.

[Настройка NPMPlus](https://github.com/ZoeyVid/NPMplus) · [Доверенные адреса в Nginx](https://nginx.org/en/docs/http/ngx_http_realip_module.html#set_real_ip_from) · [Обработка заголовков прокси в Uvicorn](https://uvicorn.dev/settings/#http)

Для доступа из локальной сети без прокси задайте в `APP_URL` адрес Windows или Debian и порт, а `APP_BIND` ограничьте нужным интерфейсом. Используйте HTTPS для соединений за пределами доверенной локальной сети.
