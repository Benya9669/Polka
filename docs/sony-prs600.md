# Sony PRS-600

Откройте «Sony PRS-600» в боковом меню или нажмите «Для Sony» рядом с файлом книги. Выберите до 25 файлов, откройте предварительный план и подготовьте ZIP. Текстовые книги конвертируются в EPUB 2 с профилем Sony. Исходные PDF сохраняются без изменений, а страницы DjVu преобразуются в PDF. Разрешённые файлы можно экспортировать и из индексируемой библиотеки. [Справка Sony о форматах PRS-600](https://www.sony.com/electronics/support/reader-digital-book-prs-series/prs-600/articles/S1F0505) · [Параметры Calibre](https://manual.calibre-ebook.com/generated/en/ebook-convert.html)

Скачайте готовый ZIP и распакуйте его вместе с `manifest.json`. Подключите ридер или карту памяти и подставьте букву нужного носителя. Из папки проекта выполните команды PowerShell. Первая показывает план, вторая копирует отсутствующие версии файлов в `Books/Polka`.

```powershell
Expand-Archive -LiteralPath 'C:\Books\polka-sony-12.zip' -DestinationPath 'C:\Books\SonyExport'
.\scripts\sync-sony.ps1 -Source 'C:\Books\SonyExport' -Drive 'E:'
.\scripts\sync-sony.ps1 -Source 'C:\Books\SonyExport' -Drive 'E:' -Apply
```

Скрипт проверяет SHA-256 по манифесту и повторяет проверку после копирования. Имена копий содержат часть хеша, поэтому повторный запуск пропускает совпадающие файлы, а изменённые версии сохраняются отдельными файлами.

Чтобы после передачи запросить безопасное извлечение выбранного носителя через Windows, добавьте `-Eject`.

```powershell
.\scripts\sync-sony.ps1 -Source 'C:\Books\SonyExport' -Drive 'E:' -Apply -Eject
```

Дождитесь сообщения утилиты о завершении безопасного извлечения. Если диск занят, утилита выводит причину отказа. Закройте открытые файлы и используйте «Безопасное извлечение устройств» в Windows. Если ридер отображает несколько дисков, убедитесь, что Windows разрешила отключить весь ридер перед отсоединением USB. [Документация Windows по безопасному извлечению](https://learn.microsoft.com/en-us/windows/win32/api/cfgmgr32/nf-cfgmgr32-cm_request_device_ejectw)

В разделе «Прогресс на Sony» можно вручную указать страницу, процент или отметить книгу прочитанной. Веб-читалка предлагает приблизительный переход по проценту для EPUB. По номеру страницы можно перейти для того же PDF. Автоматическое чтение базы PRS+ и проверка экспорта на физическом PRS-600 остаются открытыми.
