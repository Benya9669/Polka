# Управление библиотекой

Управляемая библиотека копирует оригиналы в постоянный том. Индексируемая хранит путь относительно выбранной папки `/inbox`. Подключайте Nextcloud только через read-only монтирование `BOOKS_INBOX`. Рабочие тома, обложки и конвертации размещаются отдельно.

В «Настройках библиотеки» владелец или администратор может изменить название и описание. Администратор также включает или отключает общий доступ для других пользователей. После отключения книги исчезают из их каталога и OPDS, а сохранённые позиции снова доступны им при повторном открытии общего доступа.

В тех же настройках можно задать форматы оригиналов через запятую. Пустое поле разрешает все форматы, которые поддерживает «Полка». Правило действует на загрузку файлов, импорт из OPDS, ручное и автоматическое сканирование. Форматы расписания могут дополнительно сузить общий список. Ранее добавленные книги остаются доступны, а производные EPUB и PDF создаются по обычным правилам конвертации.

В разделе «Библиотеки» запустите предварительный просмотр, затем проверьте план в разделе «Загрузки и импорт». Перед добавлением нового файла сервер сверяет контрольную сумму SHA-256 с планом. Совпадения по метаданным сопровождаются оценкой и объяснением. План учитывает совпадение ISBN, название, авторов, языки, номера томов и форматы. Разные файлы автоматически не сливаются. Повторный импорт точного дубликата возвращает существующую запись. Метаданные меняются в PostgreSQL.

В ручном плане можно пропустить файл, создать отдельную карточку или добавить файл отдельным изданием к одному из предложенных совпадений. Если оба файла ещё в очереди, план предлагает связать поздний файл с указанным ранее основным файлом. При недоступности основного файла зависимый файл отмечается ошибкой. Повторное подтверждение с теми же решениями возвращает текущую задачу.

До подтверждения план показывает число файлов с ошибками формата или метаданных, а также пересчитывает число новых карточек и конвертаций по вашим решениям. При совпадении SHA-256 план учитывает одну копию файла. Для похожих произведений число карточек меняется после выбора действия.

Отмена управляемого импорта отправляет в корзину созданные им карточки. Издания, добавленные в уже существовавшие карточки, сохраняются. Для новых импортов журнал хранит список добавленных файлов. Если в карточки позднее добавили другие файлы, сервер отклоняет отмену импорта.

## Расписание сканирования

Администратор может включить расписание отдельно для каждой библиотеки. Режим «Готовить план импорта» оставляет подтверждение в журнале операций. Режим «Импортировать автоматически» применяет план при появлении новых файлов или необходимости обновить ссылку на индексированный оригинал. В настройках доступны интервал от 1 до 10 080 минут, список форматов и подкаталог импорта для управляемой библиотеки. Пустой список форматов включает все поддерживаемые форматы.

Параметр «Сканировать при изменении файлов» ускоряет проверку, когда файловая система доставляет события. Проверка по расписанию остаётся активной, в том числе для подключённых через SMB папок. Повторный проход использует сохранённые SHA-256 и метаданные для файлов с прежними атрибутами. Количество таких файлов отображается в журнале.

Если файл индексируемой библиотеки удалён или подменён, карточка произведения и личные данные чтения сохраняются. Старая ссылка на скачивание становится недоступной. При повторном импорте точно совпадающего файла по новому пути существующая запись получает рабочую ссылку. Новое содержимое по прежнему пути проходит обычный импорт.

## Метаданные и корзина

На странице книги можно редактировать произведение и сведения об отдельных изданиях. В управляемой библиотеке можно загрузить дополнительный формат в существующее издание или добавить отдельное издание. Жанры, авторы, серии и пользовательские метки доступны в фильтрах каталога. Для массовой правки выберите книги и задайте новую серию, жанры или изменения меток.

Чтобы объединить две карточки в одной библиотеке, откройте основную и нажмите «Объединить карточки». Найдите вторую книгу по названию, автору или ISBN. Предпросмотр показывает направление объединения и список переносимых изданий. Если за время просмотра изменились метаданные или файлы, понадобится свежий предпросмотр.

Основная карточка сохраняет название и авторов. Серии, жанры, метки и дополнительные поля обеих карточек объединяются. При совпадении серии или имени поля сохраняется значение основной карточки. Издания и файлы сохраняют идентификаторы. Это сохраняет позиции, заметки и историю для каждого файла. Коллекции и избранное объединяются для каждого пользователя отдельно, а общая карточка показывает последнюю позицию. Для статуса приоритет имеет основная карточка, кроме пустого статуса или более свежей отметки о завершении во второй карточке.

Старая ссылка открывает основную карточку. Подтверждение окончательно объединяет карточки и добавляет запись в «Загрузки и импорт». Если импортированные карточки уже участвовали в объединении, отмена всего импорта недоступна.

Корзина управляемой библиотеки скрывает произведение из каталога, OPDS и чтения. При восстановлении доступны те же файлы, позиции, заметки и коллекции. В журнале можно отменить завершённый управляемый импорт, отправив его новые записи в корзину. Операции не трогают исходную папку.

## Авторы и псевдонимы

Профиль автора можно открыть из карточки книги или через раздел «Авторы». Профиль показывает книги с любым именем автора в пределах одной библиотеки. Псевдонимы работают в поиске, фильтре каталога, OPDS и оценке совпадений при импорте. На карточках и в сведениях о файлах сохраняется имя, указанное в метаданных книги.

Владелец библиотеки или администратор может добавить псевдоним или изменить основное имя. Предыдущее имя после переименования становится вариантом имени. Если под новым псевдонимом уже есть профиль в той же библиотеке, отдельное подтверждение объединяет связанные книги и остальные псевдонимы. Прежняя ссылка открывает итоговый профиль. Чтобы удалить псевдоним, указанный в карточках книг, сначала исправьте их метаданные.

## Серии, подсерии и тома

Раздел «Серии» показывает иерархию в пределах каждой библиотеки. Ветка содержит подсерии и свои тома. Числовые номера сортируются по значению, включая дробные `2.5` и `2,5`. Тома с текстовым номером или без номера идут после числовых. В OPDS 1 и 2 серии открываются через ветки и пункт «Тома серии».

В редакторе карточки можно указать несколько серий, вложенные подсерии и номер для каждой ветки. Для новых файлов импорт учитывает вложенные `sequence` из FB2, коллекции и уточнения `group-position` из EPUB 3, а также плоские поля Calibre. Уже сохранённые серии при обновлении переносятся в каталог как отдельные серии верхнего уровня. [Схема FB2](https://github.com/gribuser/fb2/blob/master/FictionBook.xsd) [Метаданные коллекций EPUB 3.3](https://www.w3.org/TR/epub-33/#sec-belongs-to-collection)

Раскладка использует первую серию карточки. Поле `{series}` подставляет её верхний уровень, `{subseries}` — путь подсерий одним компонентом, а `{series_index}` — номер тома. Подходит шаблон `{series}/{subseries}/{series_index} - {title}.{format}`.

## Раскладка файлов

Откройте «Библиотеки → Раскладка файлов». Сохраните шаблон, сформируйте предварительный план и подтвердите его. Шаблон `{author}/{series}/{series_index} - {title}.{format}` создаёт читаемые пути. План выполняется только при совпадении текущих данных с предпросмотром.

Фоновая задача проверяет каждый файл по SHA-256 и создаёт новый снимок управляемых копий внутри тома данных. Активный снимок переключается после завершения задачи. Его путь и манифест доступны на экране раскладки. Возврат переключает указатель на предыдущий снимок. Снимки занимают дополнительное место и содержат состояние на момент их создания.

| Формат | Извлечение | Веб-чтение | Конвертация |
|---|---|---|---|
| EPUB 2/3 | OPF, авторы, язык, серии, жанры, обложка из манифеста | EPUB.js, страницы и прокрутка, содержание, закладки, темы, шрифт, интервал и поля | Готовый EPUB |
| FB2 | Название, авторы, серии, язык, аннотация, издатель, ISBN, обложка | Через производный EPUB | Автоматически |
| FB2.ZIP | Одна книга FB2 внутри архива | Через производный EPUB | Автоматически |
| PDF | Заголовок и автор из PDF Info, первая страница для обложки | PDF.js, постраничное чтение, масштаб, текстовый поиск, закладки | Файл сохраняется как PDF |
| TXT | Название по имени файла | Через производный EPUB | Вручную |
| MOBI и AZW3 | Метаданные и обложка Calibre CLI при наличии | Через производный EPUB | В EPUB вручную |
| Sony LRF | Встроенные метаданные и обложка при наличии | Через производный EPUB | В EPUB вручную |
| CBZ | ComicInfo.xml при наличии и первая страница | Через производный EPUB | В EPUB вручную |
| HTML | Название из HTML | Через производный EPUB | В EPUB вручную |
| RTF | Метаданные Calibre CLI при наличии | Через производный EPUB | В EPUB вручную |
| DjVu | Название по имени файла, первая страница для обложки | Через производный PDF | В PDF вручную |

Конвертация создаёт производную копию. Для CBZ принимаются страницы JPEG и PNG с необязательным ComicInfo.xml. Для отдельного HTML конвертируется текст и базовая разметка. Скрипты, стили и ссылки на ресурсы отбрасываются. PDF-поиск требует текстового слоя. Для PDF, полученного из DjVu, OCR не выполняется. MOBI и AZW3 с DRM отклоняются.

В PDF увеличенную страницу можно прокручивать по горизонтали и вертикали внутри области чтения. При перелистывании следующая страница открывается с начала. Номер страницы сохраняется для повторного открытия книги.

Версии позиции чтения привязаны к пользователю и файлу. Для разных файлов используются отдельные локаторы. При сетевом сбое новая позиция сохраняется в браузере и повторно отправляется после подключения. При конфликте версий читалка предлагает выбрать позицию.

Для чтения офлайн откройте EPUB или PDF и нажмите «Сохранить без сети». Книгу можно снова открыть после перезагрузки по прежней ссылке или через раздел «Книги без сети». Сохранённые закладки и заметки доступны для просмотра. Для их редактирования подключитесь к серверу. Офлайн требуется браузер с поддержкой Service Worker на HTTPS или localhost. [Требования браузеров](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerContainer/register)

Копии хранятся в профиле браузера отдельно для каждого пользователя. Раздел «Книги без сети» удаляет выбранную копию, а выход из учётной записи удаляет её копии из браузера. Доступ без сети использует последнюю учётную запись, подтверждённую сервером, и требует доверенного профиля браузера.

На странице произведения можно менять статус чтения, отмечать избранное и добавлять книгу в личные коллекции. «Главная» показывает прогресс, недавние поступления и статистику. История чтения хранит отдельные открытия EPUB и PDF. Длительность округляется до секунд и учитывает только активную вкладку с недавним взаимодействием.

В EPUB выделите текст и сохраните выделение с заметкой или без неё. Для PDF сохраняются заметки к страницам. Закладки, заметки, выделения, статусы и история доступны в личном JSON-экспорте из настроек.

На странице «Раскладка файлов» в разделе «Снимки после отмены раскладки» можно нажать «Удалить снимок» и подтвердить удаление. Удаляются копии и манифест выбранного снимка. Сервер сохраняет исходные книги, текущую раскладку и все снимки, к которым ведёт последовательная отмена. Запись о создании снимка остаётся в журнале операций.
